# Decisions log

| Date | Decision | Notes |
|---|---|---|
| 2026-10-22 | **Visual style: stylized low-poly 3D only, much higher quality** | No realistic images or video, no image-generation models. Remotion + React Three Fiber stays the engine. |
| 2026-10-22 | **TTS: support both KittenTTS 2 and VoxCPM2** | The dev laptop has no NVIDIA GPU and runs Kitten only. VoxCPM2 runs on the other (GPU) machine. Kitten is the default that always works. |
| 2026-10-22 | **Audio: free CC0 libraries** | Download once and tag. No synthesized sounds, no generative audio, no paid APIs. Sonniss is excluded because of its no-AI-use clause. See [03-audio-sources.md](03-audio-sources.md). |
| 2026-10-22 | **AI provider: Ollama Pro cloud only** | Each pipeline role (writer, director, sound, critic, editor, photographer/vision) gets its own model, chosen in the UI. |
| 2026-10-22 | **Delivery: phased milestones** | Each phase ends with something runnable that the user reviews before the next phase starts. |
| 2026-10-22 | **Formats: 9:16 (15–90s), 16:9 (up to ~10 min), 1:1** | Camera framing and caption layout must adapt to the aspect ratio. Long-form stories are written act by act. |
| 2026-10-22 | **Characters: CC0 rigged low-poly** | Kenney and Quaternius/Poly Pizza packs, recoloured, with an action timeline from the director. |
| 2026-10-22 | **Editing: browser editor with live Remotion Player preview** | Edit beats, shots, captions, camera, music. "Ask AI" to change one beat. Only changed lines are re-voiced and only changed chunks re-rendered. |
| 2026-10-22 | **No off-the-shelf replacement exists, so we build it** | We borrow ideas from Cutscene Agent, FilmAgent and ClawVid. See [02-prior-art.md](02-prior-art.md). |
| 2026-10-23 | **One continuous world instead of separate stages** | Earth with countries, cities, nature, seasons and time of day, plus planets and interiors. The AI picks place, season and time from a catalog; one video can travel between places smoothly. See [06-world-engine.md](06-world-engine.md). |
| 2026-10-23 | **Cities are generated from regional style rules; no OpenStreetMap** | Public-domain base data (Natural Earth, NOAA) is fine. |
| 2026-10-23 | **CC-BY 3D models allowed, with an automatic credits line** | Needed for famous landmarks (no CC0 set exists). Each video's description lists only the CC-BY models it used. |
| 2026-10-23 | **Phase 6 added: one world and video quality** | Connects the world engine to the factory, then adds life (traffic, people, wind), night and time-lapse, "what if" world events, motion blur, a globe graphics layer, globe polish, place-based sound, and more landmarks, places, interiors and planets. Its first step comes before Phase 3. See [05-plan.md](05-plan.md#phase-6--one-world-and-video-quality--milestone-6). |
| 2026-10-23 | **Phase 7 added: The Reference Bar** | The user's quality bar is two channels (reference frames in [quality-refs/](quality-refs/)): a dressed one-world town (gravity channel) and dense NYC with animated life, tracking/aerial/close camera and a timer+BPM HUD (What If Fun facts). The 7 checklist items become acceptance criteria inside Phases 3/5/6; Phase 7 owns the typography restyle (serif captions, gold keyword highlight) and the gate: it passes only when the user says the video looks like the references. |
| 2026-10-23 | **Engines: both stay, first-class** | The user listened to the A/B set (`output/ab/`, real fixture lines) and kept **both KittenTTS 2 and VoxCPM2**. Defaults stay (Kitten = always-works CPU fallback; VoxCPM = max quality, 48 kHz, GPU). Both are per-video selectable (narration and character voices are separate switches). Future option: the sound role may mix engines per line (e.g. Kitten character voice for dialogue, VoxCPM documentary tone for narration) — the settings model already carries engine per voice class. |
| 2026-10-23 | **EKG/BPM row returns as a director-chosable device** | The reference channels drive the pulse deliberately (it rises with panic). Same evening as the deletion: `bpm` returns into `StatBeatSchema` as optional — rendered only when the director sets it, heartbeat sound derived from it by the sound designer. The fabricated always-on values and bed stay deleted. See [10-intent-audit.md](10-intent-audit.md) amendment and Phase 7 step 2. |
| 2026-10-23 | **Next: real CC0 assets and the world catalog first** | Then test NASA 3DTilesRendererJS for a continuous descent. Research first, then build (no new subsystem without a prior-art check). |
| 2026-10-23 | **Nothing may appear without AI intent (standing design rule)** | "Nothing should be random or just there; everything shown/sounded must be reasonably there by AI — only if needed, else not." Consequence: the PULSE/BPM row on the counter card and the assembler's fabricated heartbeat bed are deleted (audit + execution plan in [10-intent-audit.md](10-intent-audit.md)). Any future HUD/sound element ships only if the director/designer explicitly chooses it or it is derived from what they chose. If a premise ever genuinely needs a pulse, it returns as an intentional, schema-supported device the director can request. |
